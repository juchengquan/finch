# Phase 1.0 Implementation Plan — finch for iOS (read-only iPhone)

> _Web facts verified against commit `22c9896` (SCHEMA_VERSION `2026-06-14T00:00:00Z`), 2026-06-13.
> See `_WEB_DRIFT_CHECKLIST.md`._
> _Hardened per Phase 1.0 dry-run, 2026-06-13 (see `_PHASE_1_0_GAP_REPORT.md`)._

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a working, verifiable iOS app (iPhone 16 simulator, iOS 26+) that opens a `.finch` pack via the system file picker, displays read-only **Accounts / Activity / Budgets / Settings**, and exports a fresh `.finch` via the system share sheet. The 4 tabs cover the parity surface that exercises the 7 selectors, the audit gate, the pack engine, and the I18nError pipeline.

**Architecture:** SwiftUI iPhone target built with Xcode 16.3+ and the iOS 26+ SDK. Storage is **GRDB.swift 7.11.0** (per `IOS_MACOS_PLAN.md` §4.2) wrapping a file-backed SQLite DB in WAL mode via a single GRDB connection type — **`DatabaseQueue`** (matches DESIGN §4-step-3; one connection type used everywhere). The `FinchCore` Swift package hosts the storage layer (open, migrate, query, audit, pack) and the `Selectors` module (the 7 selectors that the iOS app needs for the 4 tabs). The `FinchApp` SwiftUI target (the XcodeGen project, Task 12) consumes `FinchCore` and renders the 4 tabs via a single `TabView`. Imports flow through the system file picker → `Pack.parse` → extract → migrate → **`auditLedger` gate** (throws on any problem; the user may override via "Force import") → atomic swap into Application Support → re-open → projection → in-memory `Tx[]` cache → `Selectors` → SwiftUI views. Exports flow the other way.

**Locked decisions applied throughout (see `_PHASE_1_0_GAP_REPORT.md` D1–D7):**
- **D1** — the pre-DE→DE migration and the `pre-de.finch` fixture are **DROPPED entirely**. Phase 1.0 is **fresh-DB-only**: the canonical `SCHEMA` already carries the post-cutover double-entry shape; there is no `cutover.ts` to port (the web removed it as dead code; it lives only in git history).
- **D2** — a web-side prerequisite **Task 0** authors the fixture oracle (`lib/select.fixtures.ts` + `scripts/export-fixtures.ts`) **before** the Swift tasks. The Swift parity tests *consume* its generated JSON; they do not extract cases from `select.test.ts`.
- **D3** — Activity search is **client-side `merchant.includes`** (exactly what the web Activity page + `selectTransactions` do). The Activity page does **NOT** use FTS5.
- **D4** — Account/Transaction **detail views are DEFERRED** out of Phase 1.0.
- **D5** — the `.xcodeproj` is generated by **XcodeGen** from a checked-in `project.yml` (agent-reproducible; no Xcode wizard).
- **D6** — zip read/write uses **ZIPFoundation, pinned** (`exact: "0.9.19"`); update DESIGN §6's "system zip" note accordingly.
- **D7** — the **"Force import"** hatch is kept, but it is a **deliberate iOS-only divergence**: the web has no audit-skip path. Label it as such wherever it appears.

## Task 0: Web-side fixture oracle (the parity source of truth)

> **This task runs on the web (TypeScript + bun) and MUST land before any Swift task.** It authors the deterministic fixture oracle that the Swift parity targets consume. Per `_CANONICAL_WEB_FACTS.md` §G, the old "scrape `CASES` out of `select.test.ts`" design cannot work — that file is 74 flat `test(…)` calls with inline literals and `Math.random()` ids. **Files:**

- Create: `frontend/scripts/export-fixtures.ts` — imports `CASES`, writes the Swift-side JSON
- Modify (optional, Phase 1.5): `frontend/lib/select.test.ts` — iterate `CASES` (the web-side oracle). For Phase 1.0 it is sufficient that `CASES` exists and is self-consistent; refactoring the 74 inline tests onto `CASES` is Phase 1.5 work.

- [ ] **Step 1: Define the fixture types + the `CASES` array**

`frontend/lib/select.fixtures.ts`:

```typescript
// frontend/lib/select.fixtures.ts — the deterministic parity oracle.
// Single source of truth for selector fixtures, consumed by BOTH the
// web-side test (lib/select.test.ts) and the Swift parity target (via
// scripts/export-fixtures.ts). FIXED ids only — NO Math.random().
import type { Tx } from '@/lib/store';
import type { AccountRow } from '@/lib/db/domain/accounts/types';
import type { BudgetRow } from '@/lib/db/domain/budgets/types';

/** One parity case. `input` is a NAMED-OBJECT (the selector's named args),
 *  NOT a positional array and NOT `unknown`. This shape is pinned here and
 *  in WIRE_FORMAT §5.1. */
export interface SelectorFixture {
  /** Stable case slug, e.g. "sums-postings". Used in the output filename. */
  name: string;
  /** One of the 7 Phase-1.0 selector names. */
  selector:
    | 'accountBalance' | 'selectTransactions' | 'categorySpend'
    | 'budgetProgress' | 'cycleWindow' | 'merchantStats' | 'anomalyScore';
  /** The selector's named arguments (object form). */
  input: Record<string, unknown>;
  /** The selector's return value, serialized. */
  expected: unknown;
}

export const CASES: SelectorFixture[] = [
  // REQUIRED: cover ALL 7 Phase-1.0 selectors, INCLUDING the three that
  // have ZERO existing tests in select.test.ts today:
  //   accountBalance, budgetProgress, cycleWindow.
  // Each case uses fixed ids (e.g. 'a1','l1','e1'), fixed dates, and a
  // `today` where the selector needs one. Author at least 2-3 cases per
  // selector (happy path + an edge: empty input, over-budget, FX, etc.).
  // NOTE: `merchantStats` RETURNS a Map<string, MerchantStats> and
  // `anomalyScore` CONSUMES one as `input.stats`. Author `expected` /
  // `input.stats` for those as Maps — the export-fixtures.ts generator runs
  // a `mapToObjectReplacer` that converts any Map → plain object before
  // JSON.stringify (a raw `JSON.stringify(map)` serializes to `{}`).
  // Example shape (fill in real expected values by running the selector):
  // {
  //   name: 'sums-postings',
  //   selector: 'accountBalance',
  //   input: { accounts: [/* AccountRow[] */], accountId: 'a1' },
  //   expected: 1234.56,
  // },
];
```

  The `input` object keys are exactly the selector's named parameters from `_CANONICAL_WEB_FACTS.md §E`:
  - `accountBalance` → `{ accounts, accountId }`
  - `selectTransactions` → `{ txns, opts }`
  - `categorySpend` → `{ txns, ledgerId, month? }`
  - `budgetProgress` → `{ budget, txns, today, categories? }`
  - `cycleWindow` → `{ frequency, startDate, today, endDate?, isRecurring? }`
  - `merchantStats` → `{ txns, ledgerId }`
  - `anomalyScore` → `{ tx, stats, opts? }`

- [ ] **Step 2: Author the `export-fixtures.ts` generator**

`frontend/scripts/export-fixtures.ts`:

```typescript
// frontend/scripts/export-fixtures.ts — Phase 1.0 artifact (does NOT exist yet).
// Imports CASES and serializes each case to the JSON the Swift parity target
// reads. ALSO generates the 10 audit-corruption fixtures. Run: `bun scripts/export-fixtures.ts`.
import * as fs from 'node:fs/promises';
import * as path from 'node:path';
import { CASES } from '../lib/select.fixtures';

// Canonical, standardized fixture root (single spelling used everywhere):
const OUT = path.join(
  __dirname, '..', 'ios', 'FinchCore', 'Tests', 'ParityTests', 'Fixtures',
);

/** `JSON.stringify` serializes a `Map` as `{}` — but `merchantStats` RETURNS a
 *  `Map<string, MerchantStats>` and `anomalyScore` CONSUMES one (as `input.stats`).
 *  Without normalization those two selectors' fixtures silently become `{}`.
 *  This replacer converts ANY `Map` (at any depth) to a plain object before
 *  serialization, so both the `expected` of merchantStats cases and the
 *  `input.stats` of anomalyScore cases round-trip to real JSON. */
function mapToObjectReplacer(_key: string, value: unknown): unknown {
  return value instanceof Map ? Object.fromEntries(value) : value;
}

async function writeSelectorFixtures() {
  for (const c of CASES) {
    // group = the selector name; file = <selector>__<case>.json
    const dir = path.join(OUT, 'selectors', c.selector);
    await fs.mkdir(dir, { recursive: true });
    await fs.writeFile(
      path.join(dir, `${c.selector}__${c.name}.json`),
      JSON.stringify(c, mapToObjectReplacer, 2),
    );
  }
}

async function writeAuditFixtures() {
  // Generate the 10 audit-corruption fixtures — one per AuditProblem.code:
  //   unsealed, unbalanced, too-few-legs, no-account-leg, currency-mismatch,
  //   cross-ledger, base-identity, kind-shape, trial-balance, balance-drift.
  // For each: spin up a fresh DB (migrate fresh), seed exactly the rows that
  // trip THAT one check, VACUUM INTO a `<code>.sqlite3`, and write a sibling
  // `<code>__<case>.json` recording the expected AuditProblem set (code +
  // entryId + detail) that the web's `auditLedger` returns for that DB.
  // IMPORTANT: the schema's invariant triggers (tr_entry_seal,
  // tr_post_sealed_insert, the posting-currency + cached-balance triggers)
  // PREVENT creating most of this corruption through normal INSERTs — that's
  // their purpose. So before seeding each fixture, DROP those triggers (or run
  // the seed on a triggers-stripped clone of the schema) and seed the FK parent
  // rows (ledgers/accounts/categories) so inserts satisfy FK constraints.
  // Without this, e.g. an unbalanced+sealed entry is simply unreachable.
  // (The balance-drift fixture seeds drift deliberately; the web's auditLedger
  //  defaults checkBalances=true so it is detected.)
}

async function main() {
  await writeSelectorFixtures();
  await writeAuditFixtures();
}
main().catch((e) => { console.error(e); process.exit(1); });
```

```swift
import GRDB

/// The iOS port's mirror of the web's migration runner
/// `migrate(exec, { fresh })` (`schema.ts:688`). Phase 1.0 is
/// fresh-DB-only: apply the canonical `SCHEMA` (already the
/// post-cutover DE shape) and stamp the metadata row. The web's

/// `MIGRATIONS` (dead code in git history only) — there is no
/// `cutover.ts` to port (D1).
public enum Migrations {
    public static func makeMigrator() -> DatabaseMigrator {
        var migrator = DatabaseMigrator()

        // The single baseline migration: apply the full canonical
        // schema, then port `ensureMetadataRow` (schema.ts:665) —
        // INSERT the single db_metadata row (id=1) with
        // app_name=Schema.appName ('finch'), schema_version=Schema.version,
        // app_version=FinchCore.version, created_at/updated_at=now.
        migrator.registerMigration("baseline-2026-06-14") { db in
            try Schema.apply(to: db)
            try Self.ensureMetadataRow(db)
        }

        return migrator
    }

    /// Port of `ensureMetadataRow` (schema.ts:665): on a fresh DB,
    /// INSERT the id=1 metadata row stamping app_name + schema_version
    /// + app_version; on an existing row, UPDATE schema_version +
    /// app_version + updated_at. (Phase 1.0 only ever hits the INSERT
    /// path since the baseline runs on a fresh DB.)
    static func ensureMetadataRow(_ db: Database) throws {
        let now = ISO8601DateFormatter().string(from: Date())
        try db.execute(sql: """
            INSERT INTO db_metadata (id, app_name, schema_version, app_version, created_at, updated_at)
            VALUES (1, ?, ?, ?, ?, ?)
            ON CONFLICT(id) DO UPDATE SET
              schema_version = excluded.schema_version,
              app_version = excluded.app_version,
              updated_at = excluded.updated_at
            """, arguments: [Schema.appName, Schema.version, FinchCore.version, now, now])
    }

    /// Run the migration on the given queue. Idempotent.
    public static func runAll(on dbQueue: DatabaseQueue) throws {
        try makeMigrator().migrate(dbQueue)
    }
}
```

```swift
import Foundation

/// Decimal money + the display-currency conversion path. Mirrors the
/// web's `useMoney` (components/use-money.ts): convert active-ledger-base
/// → display currency via the latest-rate map, then format.
public enum Money {
    public static func toDouble(_ d: Decimal) -> Double { (d as NSDecimalNumber).doubleValue }
    public static func toDecimal(_ d: Double) -> Decimal { Decimal(d) }

    /// A latest-rate map (currency → units-per-base), built from the
    /// projected exchange_rates (mirrors `latestRateMap` + `convertViaRates`).
    public struct Rates {
        public let base: String
        public let perBase: [String: Decimal]   // 1 base = perBase[ccy] of ccy
        public init(base: String, perBase: [String: Decimal]) { self.base = base; self.perBase = perBase }
        /// Convert an amount in `base` into `to`. Identity when to == base.
        public func convert(_ amount: Decimal, to: String) -> Decimal {
            if to == base { return amount }
            guard let r = perBase[to] else { return amount }  // fallback: no rate → pass through
            return amount * r
        }
    }

    /// Format an amount that is denominated in the LEDGER BASE, converted
    /// into `display`. This is the primary entry point for store/projection
    /// amounts (R6). `rates` carries the base + latest-rate map.
    public static func formatted(_ baseAmount: Decimal, in display: String, rates: Rates) -> String {
        rates.convert(baseAmount, to: display).formatted(.currency(code: display))
    }

    /// Format an amount ALREADY denominated in `currencyCode` (no conversion).
    /// Use only for genuinely native rows (e.g. FX display), not for
    /// ledger-base store amounts.
    public static func formattedNative(_ amount: Decimal, currencyCode: String) -> String {
        amount.formatted(.currency(code: currencyCode))
    }
}
```

- [ ] **Step 3: Implement the `FinchStore`**

`ios/FinchApp/Sources/FinchApp/FinchStore.swift`:

> **R4 — `loadPack` MUST mirror DESIGN §4: extract → migrate → AUDIT GATE → atomic swap → re-open → project.** The earlier version projected from the temp DB without swapping (the import vanishes on next launch) and ran the audit WITHOUT gating (dirty data imported unconditionally). Fix: throw `PackError.auditFailed(problems)` BEFORE the swap on any problem; swap the staged DB into **Application Support** (with a `.bak.<unix-ts>`, moving attachments); re-open the live DB; project. One connection type: `DatabaseQueue`.
>
> **`forceImportCurrentPack` (D7 — the iOS-only override) must retain the REJECTED pack's staged DB.** Because the gate throws `auditFailed` BEFORE the swap, the audit-failing DB never reaches the live location — so force-import cannot just "re-project the live DB" (that would re-project the *previous* clean import, not the rejected pack). Instead, `loadPack` stashes the rejected pack's **staging dir + extracted paths** (`self.pendingRejected`) when it throws `auditFailed`; `forceImportCurrentPack` then performs the *same* atomic swap of THAT staged DB into Application Support, re-opens, and projects — a real import path for an audit-failing pack (audit override is the only difference from `loadPack`).

```swift
import Foundation
import FinchCore
import GRDB

@MainActor
public final class FinchStore: ObservableObject {
    public static let shared = FinchStore()

    @Published public private(set) var txns: [Tx] = []
    @Published public private(set) var accounts: [AccountRow] = []
    @Published public private(set) var budgets: [BudgetRow] = []
    @Published public private(set) var ledgers: [Ledger] = []
    @Published public var activeLedgerId: String = "" {
        didSet { if oldValue != activeLedgerId { reprojectActiveLedger() } }  // switch → re-project (R10)
    }
    @Published public private(set) var auditProblems: [Audit.AuditProblem] = []
    @Published public private(set) var dbInfo: DatabaseInfo = .empty

    private var dbQueue: DatabaseQueue?

    /// A pack that FAILED the audit gate, with its staged (extracted) DB +
    /// attachments retained on disk so `forceImportCurrentPack` (D7) can swap
    /// THAT in. Set by `loadPack` right before it throws `auditFailed`.
    private struct PendingRejected {
        let stagedDB: URL
        let stagedAttachments: URL?
        let problems: [Audit.AuditProblem]
    }
    private var pendingRejected: PendingRejected?

    /// The persistent live DB location (survives relaunch).
    public var liveDBURL: URL {
        FileManager.default.urls(for: .applicationSupportDirectory, in: .userDomainMask)[0]
            .appendingPathComponent("finch.sqlite3")
    }

    /// Import pipeline (DESIGN §4). Throws `PackError` on any failure;
    /// on `auditFailed` the live DB is UNTOUCHED (gate is pre-swap).
    public func loadPack(from data: Data) async throws {
        // 1. Parse + 2. extract to a staging dir.
        let parsed = try Pack.parse(data)
        let staging = FileManager.default.temporaryDirectory
            .appendingPathComponent("import-staging/\(UUID().uuidString)")
        let extracted = try Pack.extract(parsed, to: staging)

        // 3. Open staged DB + migrate.
        let stagedQueue: DatabaseQueue
        do { stagedQueue = try DatabaseQueue(path: extracted.dbPath.path)
             try Migrations.runAll(on: stagedQueue) }
        catch { throw PackError.migrationFailed(step: "open+migrate", underlying: error) }

        // 4. AUDIT GATE — throw BEFORE the swap on any problem, but RETAIN the
        //    staged DB so forceImportCurrentPack (D7) can swap THAT in later.
        let problems = try Audit.run(on: stagedQueue)
        guard problems.isEmpty else {
            self.pendingRejected = PendingRejected(
                stagedDB: extracted.dbPath,
                stagedAttachments: extracted.attachmentsDir,
                problems: problems)
            throw PackError.auditFailed(problems)
        }

        // 5. Atomic swap into Application Support (+ .bak.<ts>, move attachments).
        self.pendingRejected = nil
        try swapInAndProject(stagedDB: extracted.dbPath,
                             stagedAttachments: extracted.attachmentsDir,
                             problems: problems)   // empty here
    }

    /// D7 — iOS-only override: swap the RETAINED rejected pack's staged DB
    /// (stashed by `loadPack` when the audit gate threw) into the live
    /// location — a real import path that skips ONLY the audit gate. The
    /// rejected pack's problems are surfaced in `auditProblems` for the session
    /// (so Settings still shows what was overridden). No-op if nothing pending.
    public func forceImportCurrentPack() {
        guard let pending = pendingRejected else { return }
        self.pendingRejected = nil
        try? swapInAndProject(stagedDB: pending.stagedDB,
                              stagedAttachments: pending.stagedAttachments,
                              problems: pending.problems)   // surfaced, NOT gated on
    }

    /// Shared tail of both import paths: atomic-swap the staged DB into
    /// Application Support, re-open the live DB, then project.
    private func swapInAndProject(stagedDB: URL, stagedAttachments: URL?,
                                  problems: [Audit.AuditProblem]) throws {
        try atomicSwap(stagedDB: stagedDB, stagedAttachments: stagedAttachments)
        let live = try DatabaseQueue(path: liveDBURL.path)
        self.dbQueue = live
        self.auditProblems = problems
        self.ledgers = try Projection.ledgers(dbQueue: live)
        self.activeLedgerId = ledgers.first?.id ?? ""   // didSet re-projects accounts/txns/budgets
        self.dbInfo = makeDBInfo()
    }

    private func reprojectActiveLedger() {
        guard let q = dbQueue else { return }
        self.accounts = (try? Projection.accounts(dbQueue: q, ledgerId: activeLedgerId)) ?? []
        self.txns     = (try? Projection.run(dbQueue: q)) ?? []  // all ledgers; views filter by activeLedgerId
        self.budgets  = (try? Projection.budgets(dbQueue: q, ledgerId: activeLedgerId)) ?? []
    }

    private func atomicSwap(stagedDB: URL, stagedAttachments: URL?) throws {
        // close live; rename live → finch.sqlite3.bak.<unix-ts> (overwriting
        // the previous .bak); move stagedDB → live; move staged attachments →
        // Application Support/attachments/ (overwrite on id collision); on any
        // failure roll back from .bak and throw PackError.swapFailed.
    }

    private func makeDBInfo() -> DatabaseInfo { /* fill filename/size/version/lastImportedAt/rowCounts */ .empty }

    // ---- View helpers consumed by the Task 8 tabs ----
    // (kept here so the tabs reference one definition; all money via Money + the rate map.)
    /// `today` for budget cycle windows = the **max confirmed-transaction
    /// date** (ISO YYYY-MM-DD), NOT the wall clock. The web derives the budget
    /// window anchor from the data, so the oracle's `budgetProgress`/`cycleWindow`
    /// results are computed against the latest tx date; matching that here is
    /// what makes the Swift budget windows line up with the parity fixtures.
    /// Falls back to the wall-clock date only when there are no transactions.
    public var today: String {
        txns.map(\.date).max() ?? Self.isoDay(Date())
    }
    private static func isoDay(_ d: Date) -> String {
        let f = DateFormatter()
        f.calendar = Calendar(identifier: .gregorian)
        f.locale = Locale(identifier: "en_US_POSIX")
        f.timeZone = TimeZone(identifier: "UTC")
        f.dateFormat = "yyyy-MM-dd"
        return f.string(from: d)
    }
    public var displayCurrency: String { /* active ledger's display ccy, default = base */ "" }
    public var categoryParentPairs: [(id: String, parentId: String?)] { [] }   // for recursive budget matching
    public func categoryName(_ id: String?) -> String? { nil }
    public func displayMoneyBase(_ baseAmount: Decimal) -> String { "" }        // ledger base → display
    public func displayMoney(_ amount: Decimal, from currency: String) -> String { "" } // account ccy → base → display
    public var accountGroupsOrdered: [String] { [] }
    public func accounts(in group: String) -> [AccountRow] { [] }
    public func subtotalDisplay(for group: String) -> String { "" }
    public var netWorthDisplay: String { "" }                                   // sum of includeInNetWorth == 1
    public var budgetGroupsOrdered: [String] { [] }
    public func budgets(in group: String) -> [BudgetRow] { [] }
    public var budgetTotalsDisplay: (used: String, base: String) { ("", "") }
    public func daysLeft(until ymd: String) -> Int { 0 }
}

public struct DatabaseInfo: Equatable, Sendable {
    public let filename: String
    public let sizeBytes: Int
    public let schemaVersion: String
    public let lastImportedAt: Date?
    public let rowCounts: [String: Int]
    public static let empty = DatabaseInfo(
        filename: "—", sizeBytes: 0, schemaVersion: "—", lastImportedAt: nil, rowCounts: [:]
    )
    /// Bytes → "1.2 MB" via ByteCountFormatter.
    public var formattedSize: String {
        ByteCountFormatter.string(fromByteCount: Int64(sizeBytes), countStyle: .file)
    }
    public var lastImportedAtDisplay: String {
        guard let d = lastImportedAt else { return "—" }
        return d.formatted(date: .abbreviated, time: .shortened)
    }
    /// Stable ordering for the Settings row-counts list.
    public var rowCountsOrdered: [(String, Int)] {
        rowCounts.sorted { $0.key < $1.key }.map { ($0.key, $0.value) }
    }
```

```swift
import SwiftUI
import FinchCore

struct ImportButton: View {
    @EnvironmentObject private var store: FinchStore
    @State private var isPresentingFilePicker = false
    @State private var importError: ImportError?

    var body: some View {
        Button {
            isPresentingFilePicker = true
        } label: {
            Label("Import .finch", systemImage: "square.and.arrow.down")
        }
        // Accept both `.finch` and `.zip` (a `.finch` is a zip; some
        // share sheets re-type it). The custom UTI conforms to public.zip.
        .fileImporter(
            isPresented: $isPresentingFilePicker,
            allowedContentTypes: [UTType("com.juchengquan.finch") ?? .data, .zip],
            onCompletion: handlePicked
        )
        .alert(item: $importError) { err in
            Alert(title: Text("Import failed"), message: Text(err.message),
                  dismissButton: .default(Text("OK")))
        }
    }

    private func handlePicked(_ result: Result<URL, Error>) {
        switch result {
        case .success(let url):
            // Read the bytes synchronously inside the security scope, then do
            // the async import INSIDE the Task with a do/catch that surfaces
            // PackError to the alert (the earlier version's `try await`
            // escaped uncaught).
            let didStart = url.startAccessingSecurityScopedResource()
            defer { if didStart { url.stopAccessingSecurityScopedResource() } }
            guard let data = try? Data(contentsOf: url) else {
                importError = ImportError(message: "Could not read the file."); return
            }
            Task { @MainActor in
                do { try await store.loadPack(from: data) }
                catch PackError.auditFailed(let problems) {
                    importError = ImportError(
                        message: "\(problems.count) audit problem(s). Use Settings › Advanced › Force import to override (iOS only).")
                } catch let e as PackError {
                    importError = ImportError(message: String(describing: e))
                } catch {
                    importError = ImportError(message: error.localizedDescription)
                }
            }
        case .failure(let error):
            importError = ImportError(message: error.localizedDescription)
        }
    }
}

struct ImportError: Identifiable {
    let id = UUID()
    let message: String
}
```

Add to `FinchStore`:

> **R11 — `VACUUM INTO` via GRDB, NOT the raw `sqlite3_*` C API; and port the web's clone-stamp dance** (`server.ts::exportPackBytes` → `pack.ts::buildPack`): clone the live DB → **stamp export metadata** (write `exported_at`/`exported_from`/`row_counts` into the cloned `db_metadata`; set `exported_from.device = "ios"`) → **`wal_checkpoint(TRUNCATE)`** so the clone is a single self-contained file → read its bytes → compute the manifest `db.sha256` = sha256 of those bytes → `Pack.build`. NOTE: the web ALSO stamps a `db_metadata.checksum` (a canonical-table row-dump hash via `computeChecksum`); Phase 1.0 DEFERS that (leaves the column NULL — the web importer skips it when absent), so do NOT block on porting `computeChecksum`.

```swift
public func buildPack() async throws -> Data {
    guard let live = dbQueue else { throw PackError.exportFailed(underlying: ExportError.noPackLoaded) }
    do {
        // 1. VACUUM INTO a temp clone — through GRDB, not sqlite3_open/exec.
        let cloneURL = FileManager.default.temporaryDirectory
            .appendingPathComponent("export-\(UUID().uuidString).sqlite3")
        try live.read { db in
            try db.execute(sql: "VACUUM INTO ?", arguments: [cloneURL.path])
        }
        // 2. Open the clone, stamp export metadata + checkpoint the WAL.
        //    Mirrors the web's exportPackBytes → buildPack (server.ts:732-738).
        let clone = try DatabaseQueue(path: cloneURL.path)
        let rowCounts = try Projection.rowCounts(dbQueue: clone)   // 15 canonical tables
        let exportedAt = ISO8601DateFormatter().string(from: Date())
        let exportedFrom = PackManifest.ExportedFrom(
            device: "ios", deviceId: nil, deviceName: nil)
        let rowCountsJSON = String(
            data: try JSONSerialization.data(withJSONObject: rowCounts), encoding: .utf8)!
        try clone.write { db in
            // stampExport (real code, not a comment): write the export metadata
            // into the clone's db_metadata BEFORE we read its bytes.
            try db.execute(sql: """
                UPDATE db_metadata
                   SET exported_at = ?, exported_from = ?, row_counts = ?, updated_at = ?
                 WHERE id = 1
                """, arguments: [exportedAt, "ios", rowCountsJSON, exportedAt])
            // wal_checkpoint(TRUNCATE) so the clone is a single self-contained file
            // (the stamping UPDATE just wrote to the -wal; drain it into the main file).
            try db.execute(sql: "PRAGMA wal_checkpoint(TRUNCATE)")
        }
        // 3. manifest db.sha256 = sha256 of the now-self-contained clone bytes,
        //    then build the pack with the stamped metadata.
        let dbBytes = try Data(contentsOf: cloneURL)
        let checksum = Pack.sha256Hex(dbBytes)
        return try Pack.build(BuildPackInput(
            dbBytes: dbBytes,
            attachmentFiles: [],   // Phase 1.0: no attachments
            meta: PackMetadata(
                appVersion: FinchCore.version,
                schemaVersion: Schema.version,
                exportedAt: exportedAt,
                rowCounts: rowCounts,
                exportedFrom: exportedFrom,   // device = "ios" → parity test passes
                checksum: checksum            // → manifest db.sha256
            )
        ))
    } catch { throw PackError.exportFailed(underlying: error) }
}

enum ExportError: Error { case noPackLoaded }
```
