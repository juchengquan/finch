# finch for iOS & macOS

The native port of finch. Design arc: `plans/ios-macos/IOS_MACOS_INDEX.md`;
Phase 1.0 plan: `plans/ios-macos/IOS_MACOS_PHASE_1_0_PLAN.md`.

**UI convention:** SwiftUI-first — see [`swiftui-vs-uikit.md`](swiftui-vs-uikit.md) for
when (not) to reach for UIKit/AppKit.

## Layout

- `FinchCore/` — the SwiftPM package: the read-side core (schema, projection,
  audit, pack, selectors) + its tests (`FinchCoreTests`) + the macOS parity
  target (`ParityTests`, which consumes the fixtures generated by the web-side
  `frontend/scripts/export-fixtures.ts`).
- `FinchApp/` — the SwiftUI app target. Built via the Xcode project (Task 12 /
  XcodeGen), **not** SwiftPM. Shared by the iOS app, the macOS app (`FinchMac`),
  the Widget / Share extensions, and the Watch app.

## Build & test (FinchCore)

```bash
cd ios
swift build
swift test
```

## Regenerate parity fixtures

```bash
cd ../frontend && bun scripts/export-fixtures.ts
```

After changing `WRITE_SEQUENCE`, keep only `sequence.json`; the audit / projection
/ round-trip fixtures change only by `datetime('now')` noise — revert them. Avoid
adding wall-clock-dated actions to the sequence (e.g. `postScheduled`, or
`createAccount` with `openingBalance`) — their entries are stamped "today", so the
oracle would pass the day it's generated and fail the next.

## Build & run the apps

> The Xcode project `FinchApp.xcodeproj` is **generated by XcodeGen and
> git-ignored** — it isn't in the repo, and editors that respect `.gitignore`
> (e.g. VS Code) hide it from the file tree. Generate it first; new source files
> under `FinchApp/Sources/` only enter the project after a regen.

```bash
cd ios
xcodegen generate          # brew install xcodegen, if needed
open FinchApp.xcodeproj
```

CLI note: if `xcode-select -p` points at `CommandLineTools`, prefix `xcodebuild`
with `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`.

### iOS app → the Simulator

Xcode: scheme **FinchApp** → an **iPhone** destination → **⌘R** (runs in the
Simulator app). From the CLI:

```bash
xcodebuild build -scheme FinchApp -destination 'platform=iOS Simulator,name=iPhone 17' \
  -derivedDataPath /tmp/finchios
xcrun simctl boot "iPhone 17"; open -a Simulator
xcrun simctl install booted /tmp/finchios/Build/Products/Debug-iphonesimulator/FinchApp.app
xcrun simctl launch booted com.juchengquan.finch
```

### macOS app → a native window (NO simulator)

macOS has **no simulator** — the Mac app runs directly on your Mac (a window +
Dock icon). Xcode: scheme **FinchMac** → **My Mac** → **⌘R**.

`FinchMac` signs **ad-hoc** ("Sign to Run Locally", `CODE_SIGN_IDENTITY = -`), so
it builds and runs with **no Development Team** — Apple Silicon requires at least
an ad-hoc signature to launch. To make team-less signing possible, the team-only
**App Group** was dropped from `FinchApp/FinchMac.entitlements` (App Sandbox
stays; `AppGroup.containerURL` falls back to Application Support, so nothing
crashes — and no Mac widget consumes the snapshot). From the CLI:

```bash
xcodebuild build -scheme FinchMac -destination 'platform=macOS' -derivedDataPath /tmp/finchmac
open /tmp/finchmac/Build/Products/Debug/finch.app
```

### Signing & CloudKit (provisioning)

CI builds the **simulator** unsigned (`CODE_SIGNING_ALLOWED: NO`) and must stay
that way; CI does **not** build `FinchMac`. For a **device** build, set a
`DEVELOPMENT_TEAM` locally (don't commit it). For **distribution**, restore the
App Group + set a real team. CloudKit sync stays inert until its container is
provisioned — see `plans/ios-macos/IOS_MACOS_PHASE_8_CLOUDKIT_SETUP.md`.
