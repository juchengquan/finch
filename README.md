# finch for iOS & macOS

The native port of finch. Design arc: `plans/ios-macos/IOS_MACOS_INDEX.md`;
Phase 1.0 plan: `plans/ios-macos/IOS_MACOS_PHASE_1_0_PLAN.md`.

## Layout

- `FinchCore/` — the SwiftPM package: the read-side core (schema, projection,
  audit, pack, selectors) + its tests (`FinchCoreTests`) + the macOS parity
  target (`ParityTests`, which consumes the fixtures generated by the web-side
  `frontend/scripts/export-fixtures.ts`).
- `FinchApp/` — the SwiftUI app target. Built via the Xcode project (Task 12 /
  XcodeGen), **not** SwiftPM.

## Build & test (FinchCore)

```bash
cd ios
swift build
swift test
```

## Regenerate parity fixtures

```bash
cd ../frontend && bun scripts/export-fixtures.ts
```
